# AegisAuth 1.0.0 - Security Hardening & Potion Effects

- Server Compatibility: Full support for Paper, Purpur, Spigot 1.21.x / 26.1.x.
- Potion Effects: Added Blindness and Slowness visual/movement impairment for unauthenticated players until successful login or registration.
- Advanced Bypass Protection: Blocked eating, item swapping (F key), inventory dragging, vehicle entering, portal teleportation, entity targeting, bed sleeping, and flight while unauthenticated.
- Command Suggestion Protection: Filtered client command tab completions (PlayerCommandSendEvent) to hide server commands before authentication.
